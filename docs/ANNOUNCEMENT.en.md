# Meet Hermes Mobile 7.6.1

**Your agents. Your conversations. Your server. Now in your pocket.**

Hermes Mobile brings a self-hosted Hermes workspace to Android. Start on your desktop, pick up your phone, and continue the same agent conversation—with its identity intact.

## More than a chat window

Meet your real Hermes profiles in the Bots workspace. Open their conversations, start a new one with the right specialist, or keep custom companion cards for your own personalities and templates. Small original companion faces and drag-to-group teams give the workspace personality without turning ordinary chat into a complicated control panel.

When work branches into subagents, the conversation's task pipeline can show the server's live roster, supplied progress, model and tool/token counters, summaries and file information. You can see the work behind a response without treating missing data as a measured zero.

## Read, listen, open and act

Select message text. Follow a link. Open a downloaded HTML document inside the app. Use explicit audio/video controls and supported image previews alongside Markdown and code. HTML document previews run without JavaScript or access to your phone's files, and authenticated media downloads keep the server token away from external browsers and decoders.

Native macros turn small routines into understandable rules: a charging notification, a quick vibration, media-volume adjustment or flashlight action. Try a recipe manually, review the result, then enable its device trigger. Unsupported imported actions are reported instead of quietly substituted.

Voice, assistant entry points and permissioned phone tools connect the experience to Android. Your configured models and services provide the intelligence; Android permissions and the existing approval system still govern device actions.

## Built for a workspace you control

Use your own Hermes Dashboard address and token. Keep access to sessions, cron jobs, models, skills, MCP tools, files, terminal operations, approvals and selected-chat archives. Optional custom-bot and phone-bridge services extend the same workspace rather than requiring a hosted Hermes Mobile account.

Android Auto/Mola includes distinct messaging and parked-screen paths, saved vehicle preferences and consent-based mirroring on compatible hosts. It retains driving restrictions; installation success on a phone is not a promise of support in every car.

## An honest preview

The delivered implementation passed 1,573 Android unit tests on Windows and another 1,573 on macOS. Physical-phone checks included canonical session opening, HTML preview and link handling, an audio preview and a real manual notification macro.

Real head units, automatic charging events, reboot recovery, populated live subagent tasks and broader device/media testing remain separate acceptance steps. Full Mika/Phongent and OpenTasker runtimes are not embedded. Universal call recording and CSC changes are not completed features of this preview.
