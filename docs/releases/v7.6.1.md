# 7.6.1 preview: source release notes

The source is updated to versionCode 30 / versionName 7.6.1. This repository update does not by itself publish an APK release asset. Verify an asset's actual version before installing.

## Included changes

- Canonical Hermes profile cards and profile-scoped conversation resume.
- Incremental conversation pages, pinned-row deduplication and visible loading/retry states.
- Subagent event/roster observability in the active conversation.
- HTML document/code previews, audio controls, server media and supported multipart content.
- Macro result dialogs and logging of permission/precondition failures.
- Persistent acknowledgement of historical crash notices.
- English feature documentation, upstream credits and retained license/NOTICE texts.

These are scoped results, not proof of every provider, phone, vehicle or automation. Publication also adds documentation/attribution and removes a machine-specific Gradle JDK path. No credentials, private chat exports, device identifiers or raw audit logs are included in the new publication payload.

Remaining acceptance: a real head unit, physical charging event, reboot startup, a populated live subagent task, long unread-position/restart scenarios and a dedicated physical image/video matrix. Call recording and CSC modification were deferred. Historical backend tests are not presented as newly rerun Android or live-device checks.

The Mola SDK binary is omitted from publication by explicit maintainer choice. Reproducing the full local preview requires an authorized local SDK file; see `docs/BUILDING.md`. The published metadata does not assert that a clean checkout without that prerequisite builds successfully.
